# IP-SAKTI Sahayak

AI-driven, multilingual RAG assistant for Ayurveda Intellectual Property protection.

**Problem Statement ID:** SIH26045 (Ministry of Ayush)
**Theme:** MedTech / BioTech / HealthTech

## Structure
- `backend/` — FastAPI + OpenRouter (Gemini)
- `frontend/` — Next.js 14 + Tailwind CSS

## Run Locally
**Backend:**
cd backend
source venv/bin/activate
uvicorn main:app --reload

**Frontend:**
cd frontend
npm run dev
